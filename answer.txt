Часть 1.
1. Команда: echo $$
    Вывод: Выведет идентификатор текущего процесса.

2. Команда: cd /proc/[pid процеса]/
    Вывод: Позволяет перейти в каталог, который содержит все файлы с информацией о запущенных процессах.

3. Команда: cd /proc/[pid]/cwd
            ls
    Вывод: Позволяет перейти в каталог и просмотреть всё его содержимое.

4. Команда: cd /proc/[pid]/fd/
            ls -l
    Вывод: Переходит в подкаталог, в котором хранятся все открытые файлы процесса.

Ответ на вопрос: Определение потоков ввода и вывода:
```
@Wynazanar ➜ /proc/1102/cwd $ cd /proc/1102/fd
@Wynazanar ➜ /proc/1102/fd $ ls
**0  1  2**  255  6
@Wynazanar ➜ /proc/1102/fd $ ls -l
total 0
lrwx------ 1 codespace codespace 64 Feb 18 10:50 0 -> /dev/pts/0
lrwx------ 1 codespace codespace 64 Feb 18 10:50 1 -> /dev/pts/0
lrwx------ 1 codespace codespace 64 Feb 18 10:50 2 -> /dev/pts/0
lrwx------ 1 codespace codespace 64 Feb 18 10:50 255 -> /dev/pts/0
l-wx------ 1 codespace codespace 64 Feb 18 10:50 6 -> /dev/null
```
Здесь 0 - стандарт ввода, 1 - стандарт вывода и 2 - поток ошибок.

Дескрипторы нужны, потому что:
    1. Позволяют писать переносимый код, который будет работать на разных платформах, на которых есть ввод и вывод.
    2. Потоки легко переадресовывать в нужные файлы, что удобно для обработки ввода, вывода и ошибок.
    3. Стандартный вывод используется для передачи результатов программы, а поток ошибок используется для предупреждения о проблемах.

    
Часть 2.
1. Команда: echo "Hello, im from nkeIvt";
    Вывод: Hello, im from nkeIvt
    Текст отправлен в стандартный вывод.

2. Команда: ls nonexistent_file 2>&1
    Вывод: Ошибка отправляется в стандартный поток ошибок, т.к. файл не существует.

3. Команда: ls /etc /noexistfile 1>output.txt 2>errors.txt
    Вывод: Вывести содержимое файла не получится, он не существует. Сообщение об ошибке сохранится в файл `errors.txt`.

4. Команда: cat output.txt cat errors.txt
    Вывод: Выведет содержимое файлов output.txt и errors.txt.

Ответ на вопрос: Потоки вывода и ошибок можно разделять, потому что стандартный вывод нужен для нормальной работы программы и вывода её результатов. А поток ошибок применяется для записей предупреждений, ошибок и сбоев.
